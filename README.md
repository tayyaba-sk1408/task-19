# Interactive Star Rating

A simple and responsive star rating component built using HTML, CSS, and JavaScript.

## Project Overview

This project allows users to select a rating from 1 to 5 stars. Users can hover over the stars to preview a rating and click a star to select it.

The selected rating is displayed below the stars.

## Features

- 5 clickable stars
- Hover preview effect
- Rating selection from 1 to 5
- Displays the current rating
- Reset rating button
- Responsive design
- Simple and user-friendly interface

## Technologies Used

- HTML5
- CSS3
- JavaScript
